B. 기업 정체성 재정의

구분내용
시장의 레거시 잣대"PC CPU 회사 + 적자 파운드리". PC 출하량과 TSMC 격차로 평가.
실제 이동 방향① 에이전틱 AI 서버 CPU(DCAI 3Q $7.3B, +78%) ② 미국 유일 선단 파운드리 + 첨단 패키징(EMIB/EMIB-T) ③ 커스텀 ASIC/IPU(Google 공동개발).
성격 변화제품 회사 → AI 인프라 레이어(호스트 CPU + 패키징 + 웨이퍼). NVIDIA DGX Rubin NVL8 호스트 CPU 채택 확정.
매출 구조DCAI 비중 1Q26 약 40% → 3Q26 약 47%. 클라이언트 의존도 하락 중.
마진·lock-inDCAI 영업이익률 42% (3Q). x86 소프트웨어 lock-in + 공급 부족 시 가격 결정력(PC CPU +10% 인상 보도).
멀티플 함의DCAI·패키징이 커질수록 30~40배 정당화. 외부 파운드리 고객이 없으면 "사이클 반도체 20배대"로 회귀.

E. 반대 thesis (같은 강도로)

  • 우연의 연결: Terafab·Apple·SK hynix·Google은 대부분 "평가 중"이거나 부인. 서명된 대형 웨이퍼 계약은 아직 0건 공개 확정.
  • 과대평가: CPU 수요는 공급 부족 덕에 좋아 보이는 것일 수 있음. AMD는 서버 +70% 가이드, 인텔은 "공급 따라 점유율" — 점유율 방어 불확실.
  • 희석으로 EPS 정체: 주식 수 +17%/년. 2027 FCF 마이너스 → 추가 증자 시 EPS 성장 대부분 상쇄.
  • 매크로: Fed가 9월 인상(3.75~4.00%), 10년물 약 4.9~5.2%, CPI 3.4%. 고멀티플 반도체에 불리. 실업률 4.2%로 PC 소비 둔화.
  • Squeeze 후 급락 구조: 1년 +700% 랠리 후 −55%. 숏 비중이 낮아 "숏커버 반등"도 제한적.
  • M&A/분사 기대 과열: 정부 워런트·비지배지분이 파운드리 분리를 어렵게 함. "Ohio 특별 기회" 발언은 내용 미공개.
  • 안전 리스크: Fab 28 사망 사고 → 이스라엘 생산 차질 1Q27까지, 규제·소송 리스크 검증 필요.
