A. 기업 정체성 재정의

시장이 보던 회사

전통적으로 SK하이닉스는 DRAM/NAND 가격 사이클, 재고 조정, capex 과잉 여부로 할인받는 memory beta였다. 이 잣대에서는 peak P/E와 trough P/B가 더 중요하고, 72% 영업이익률은 곧 정상화될 peak margin으로 해석된다.

실제로 이동 중인 밸류체인

HBM4, custom base die, Advanced MR-MUF, AI server DRAM, SOCAMM2, eSSD까지 묶어 Nvidia 및 hyperscaler AI 시스템의 메모리 대역폭·전력·패키징 병목을 해결하는 설계 레이어로 진화 중이다. 단순 부품 판매에서 reference allocation/platform에 가까워지는 변화다.

이 변화가 맞다면 매출은 spot DRAM보다 multi-year allocation 성격이 강해지고, 고객 구조는 PC/mobile OEM에서 AI accelerator ecosystem으로, 마진은 commodity spread에서 scarcity rent로, 밸류에이션은 memory cycle multiple에서 AI infrastructure bottleneck multiple로 이동한다. 단, 이것은 영구적 플랫폼 전환이 아니라 HBM4/HBM4E 세대에서 유지되는 2~4년짜리 구조적 프리미엄으로 보는 것이 더 안전하다.

F. 생태계 Game Theory

Nvidia가 원하는 것

메모리 부족으로 GPU 매출이 제한되는 것을 막는 것. 다중공급은 필요하지만, 가장 빠르게 qualification된 공급자에게 allocation premium을 줄 유인이 크다.

Hyperscaler가 원하는 것

GPU/ASIC cluster 납기를 맞추는 것. SK를 직접 인수하기보다 선급금·장기계약·co-investment로 capacity를 확보하는 편이 현실적이다.

경쟁사가 원하는 것

Samsung/Micron은 HBM4 qualification으로 가격결정권을 분산시키려 한다. 성공하면 SK의 scarcity rent는 낮아진다.

M&A optionality: SK하이닉스 자체 피인수는 규모·국가전략산업·SK그룹 지배구조 때문에 base case 0%로 둔다. 반대로 현실적인 optionality는 미국 ADR/신주, Nvidia·TSMC·hyperscaler와 capacity lock-up, 패키징 JV/선급금이다. 가격에는 base case 0~2%, bull case 3~5%, overshoot case 10% 정도의 전략 프리미엄만 반영한다.

G. 반대 Thesis — 같은 강도의 Bear Case

반대 thesis: 현재 연결된 사건들은 모두 “AI memory supercycle”이라는 하나의 이야기로 보이지만, 실제로는 주가가 먼저 올라가고 사후적으로 모든 사건을 narrative에 끼워 맞춘 것일 수 있다. Q1 72% margin은 고객 lock-in이 아니라 공급 부족의 peak margin일 수 있고, HBM4 다중공급이 시작되면 ASP와 share가 동시에 정상화될 수 있다.

2. 전통적 비즈니스 모델의 진화

레거시 사업은 commodity DRAM/NAND 판매다. 현재 성장 축은 HBM3E/HBM4, AI server DRAM, SOCAMM2/LPDDR, eSSD다. 과거 고객군은 PC·mobile·server OEM 중심이었다면 미래 고객군은 Nvidia/accelerator vendor, hyperscaler, advanced packaging ecosystem으로 무게중심이 이동한다. SK하이닉스가 “turnkey platform” 회사까지 간다고 단정할 수는 없지만, HBM4에서는 reference design에 가까운 공동 qualification layer로 이동 중이라고 판단한다.

4. 고객·파트너·생태계 분석

NVIDIA와의 관계가 핵심이지만 단일 고객 thesis로만 보면 위험하다. 더 중요한 구조는 Nvidia roadmap이 HBM뿐 아니라 LPDDR, server DRAM, eSSD까지 memory bottleneck을 확산시키는 것이다. AMD·hyperscaler는 후보/간접 수요로 보되, 현재 공개자료만으로는 Nvidia와 같은 신뢰도로 단정하지 않는다. Qualcomm·Intel·Apple은 메모리 고객/생태계 관점의 관련성은 있으나 이번 thesis의 중심은 아니다. SpaceX·Globalstar·Gogo·Skylo·Verizon은 위성/통신 narrative와 혼동하지 말고 관련성 낮음으로 처리한다.

7. 기술 분석

핵심 제품명은 HBM3E 8/12단, HBM4 12단, 1c LPDDR6, 192GB SOCAMM2, GDDR7 24Gb, 321-layer QLC cSSD/eSSD다. 강점은 단순 DRAM cell node가 아니라 HBM stack + MR-MUF packaging + 고객 qualification + supply allocation의 결합이다. 이 레이어는 소프트웨어 대체가 어렵고, 고객 전환에는 재검증·열/전력 프로파일·패키지 설계·수율 안정화 비용이 따른다.
