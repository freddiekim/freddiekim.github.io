A. 기업 정체성 재정의

시장의 레거시 잣대: SMART Global Holdings 시절의 기억은 특수 메모리 모듈, LED, 하드웨어 조립, HPC 프로젝트 매출의 혼합체다. 이 프레임에서는 P/S 1배 안팎, P/FCF mid-teens 이하의 “cyclical hardware”로 보기 쉽다.

실제 이동 중인 밸류체인: 회사는 스스로를 “memory and AI infrastructure powering AI factories for enterprises, sovereign AI initiatives, and neocloud providers”라고 정의하고, full-stack AI factory platform을 memory·compute·software·services·partner ecosystem으로 묶는다. 핵심은 GPU를 만드는 것이 아니라, GPU 투자가 실제 inference 서비스로 전환되는 운영 레이어를 제공하는 것이다.

멀티플 변화 조건: 단순 memory module 매출이면 P/FCF 12~18x가 합리적이다. 그러나 MemoryAI/ICE/OriginAI가 반복 가능한 reference platform으로 매출총이익률과 customer lock-in을 높이면 22~27x P/FCF까지 re-rating 가능하다. 현재 주가는 이미 이 중간 이상을 가격에 반영한다.

CXL memory pooling, KV cache offload, NVIDIA Dynamo compatibility, GPU/CPU/shared memory architecture, OriginAI reference design, ICE health monitoring/auto-remediation, 서비스형 구축 경험이 결합될 때 switching cost가 생긴다. 이는 실리콘 단품 해자와 다르지만, production AI factory에서는 실제 downtime과 utilization을 좌우하는 운영 해자다.

F. 생태계 Game Theory와 M&A Optionality

누가 PENG를 필요로 하는가? regulated enterprise, sovereign AI, neocloud는 GPU만 사서는 운영 가능한 AI factory를 만들기 어렵다. 이들에게 PENG는 “검증된 reference platform + deployment/service + memory bottleneck solution” 역할을 한다. SKT/SK hynix는 AI data center를 반도체·메모리·전력·냉각·운영 소프트웨어로 묶으려 하므로 PENG가 중간 연결부가 된다.

전략적 인수 후보: Base case에는 M&A 가치를 $0로 둔다. Bull case에는 SKT/SK hynix ecosystem, Dell/HPE, Marvell/Celestial AI 인접 optionality를 주당 $5~8만 반영한다. Overshoot case에서는 strategic bid rumor 또는 board-sanctioned proposal 가능성으로 주당 $15~20의 옵션가치가 붙을 수 있다. 단, SK investor agreement와 Delaware anti-takeover 조항은 hostile bid를 어렵게 하고 friendly deal을 유리하게 만든다.

가장 가능성 높은 전략적 축: SKT/SK hynix가 가장 높은 전략 적합도를 가진다. 이미 preferred equity, board designee, AIDC collaboration, Rebellions partnership이 연결되어 있기 때문이다. 하지만 2026년 5월 30일 현재 인수 논의는 확인되지 않았고, 가격에 과도 반영하면 안 된다.

G. 반대 Thesis

반대 thesis를 같은 강도로 보면: Q2의 Integrated Memory 급성장은 AI inference 구조 변화가 아니라 메모리 가격/재고 타이밍 효과일 수 있다. Advanced Computing은 여전히 전년 대비 -42%였고, non-hyperscale AI/HPC가 좋아져도 hyperscale hardware 미반복과 Edge wind-down을 완전히 상쇄하지 못할 수 있다. CXL/KV Cache는 기술적으로 매력적이지만, 고객이 GPU vendor 또는 Dell/HPE/SMCI의 bundle로 대체하면 PENG의 margin premium은 제한된다. SK preferred는 strategic validation이지만 동시에 6.096M주 오버행이다.
